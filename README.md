# Emobile — прайс-лист и калькулятор ремонта телефонов

Сайт мастерской: клиенты выбирают бренд и модель, отмечают нужные услуги и сразу видят итоговую цену в ₪.
Интерфейс на русском и иврите (кнопка 🌐, иврит справа налево).

Сайт: https://servismaster.duckdns.org

## Как это устроено

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт одним файлом. Можно открыть двойным щелчком на компьютере, тогда работает локальный режим с редактором. |
| `server/server.py` | Маленький сервер на Python (без зависимостей): вход по паролю и сохранение прайса. |
| `server/setup-template.sh` | Шаблон установщика для Ubuntu: nginx, https (certbot), служба `servis-master`. |
| `build.py` | Собирает `servis-setup.sh`: шаблон + server.py + index.html в одном файле. |
| `servis-setup.sh` | Готовый установщик. Его копируют на сервер и запускают. |

**Клиенты** открывают сайт без пароля и видят только прайс и калькулятор.
**Мастер** нажимает на замок в шапке, вводит пароль и редактирует цены, услуги и модели прямо на сайте. Изменения сразу видят все.

Прайс хранится на сервере в `/var/lib/servis-master/prices.json`, резервные копии лежат в `/var/lib/servis-master/backups/` (последние 100). Пароль и прайс в репозиторий не попадают.

## Установка или обновление на сервере

С компьютера под Windows (PowerShell):

```
scp servis-setup.sh root@129.121.150.100:/root/
ssh -t root@129.121.150.100 "bash /root/servis-setup.sh"
```

При первой установке скрипт попросит придумать пароль для редактора. При повторном запуске пароль и цены сохраняются.

- Сменить пароль: `ssh -t root@129.121.150.100 servis-password`
- Другой домен: `bash servis-setup.sh --domain=example.com`

## Изменить сайт

1. Правите `index.html` (или `server/`).
2. `python3 build.py` пересобирает `servis-setup.sh`.
3. Копируете его на сервер и запускаете, как выше.
